# algo_transport

地球化学物质迁移算法模块，包含：
- Fick扩散（fick_diffusion.py）
- 对流-弥散方程（advection_dispersion.py）
- 色谱分离理论板数（chromatography.py）

每个文件均提供了基础函数接口，便于后续扩展。

The geochemical substance migration algorithm module comprises:
- Fick diffusion (fick_diffusion.py)
- Advection-dispersion equation (advection_dispersion.py)
- Number of theoretical plates for chromatography separation (chromatography.py)

Each file provides a basic function interface to facilitate subsequent extensions.
