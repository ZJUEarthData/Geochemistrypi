# algo_kinetic

地球化学动力学算法模块，包含：
- 一级反应动力学（first_order.py）
- 二级反应动力学（second_order.py）
- 放射性衰变（radioactive_decay.py）
- 吸附动力学（adsorption_kinetics.py）

每个文件均提供了基础函数接口，便于后续扩展。

The geochemical dynamics algorithm module includes:
- First-order reaction kinetics (first_order.py)
- Second-order reaction kinetics (second_order.py)
- Radioactive decay (radioactive_decay.py)
- Adsorption kinetics (adsorption_kinetics.py)

Each file provides a basic function interface to facilitate subsequent extensions.
