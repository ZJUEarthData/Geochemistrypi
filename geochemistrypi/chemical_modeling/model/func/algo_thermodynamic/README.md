# algo_thermodynamic

地球化学热力学算法模块，包含：
- 吉布斯自由能最小化（gibbs_minimization.py）
- 活度系数模型（activity_coefficient.py）
- 范特霍夫方程（vanthoff.py）

每个文件均提供了基础函数接口，便于后续扩展。

The geochemical thermodynamic algorithm module includes:
- Gibbs free energy minimization (gibbs_minimization.py)
- Activity coefficient model (activity_coefficient.py)
- van't Hoff equation (vanthoff.py)

Each file provides a basic function interface to facilitate subsequent extensions.
