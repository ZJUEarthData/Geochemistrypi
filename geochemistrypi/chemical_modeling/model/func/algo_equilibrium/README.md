# algo_equilibrium

地球化学平衡算法模块，包含：
- 质量平衡（mass_balance.py）
- 溶解-沉淀平衡（precipitation_dissolution.py）
- 离子交换（ion_exchange.py）

每个文件均提供了基础函数接口，便于后续扩展。

The geochemical equilibrium algorithm module includes:
- Mass balance (mass_balance.py)
- Dissolution-precipitation equilibrium (precipitation_dissolution.py)
- Ion exchange (ion_exchange.py)

Each file provides a basic function interface to facilitate subsequent extensions.
